A.1Glossaire

Bridge (pont)Mécanisme qui fait passer la valeur d'un token d'une blockchain à une autre.
Burn & mintLe token est détruit (burn) sur la chaîne source et créé (mint) en même quantité sur la chaîne de destination ; l'offre totale est conservée.
Lock & mintVariante : le token est verrouillé dans un contrat sur la source et un jeton représentatif est minté sur la destination.
ERC20Standard de token fongible sur les chaînes compatibles Ethereum (EVM).
EVMMachine virtuelle d'Ethereum ; TELA (Besu) et Sepolia l'implémentent toutes deux.
SepoliaRéseau de test public d'Ethereum (chain ID 11155111), en preuve d'enjeu ; ses ETH n'ont pas de valeur.
TELATalan Enterprise Ledger Architecture : blockchain privée EVM sur nœuds Hyperledger Besu, opérée par Talan.
Besu · TekuClients Ethereum open source en Java : Besu pour l'exécution, Teku pour le consensus.
QBFTConsensus à tolérance byzantine utilisé par les réseaux Besu privés ; finalité immédiate si moins d'un tiers des validateurs est défaillant.
FinalitéMoment où un bloc ne peut plus être annulé selon les règles du réseau. Sur Sepolia, tag finalized (≈ 13 min).
RéorganisationRemplacement de blocs récents par une autre branche ; un événement observé peut disparaître.
RelayerService hors chaîne qui observe une chaîne et soumet des transactions sur l'autre.
RPC (JSON-RPC)Interface d'accès à un nœud : lecture d'état, d'événements, envoi de transactions.
FaucetService qui distribue gratuitement des jetons natifs de test pour payer le gas.
GasUnité de coût d'exécution d'une transaction, payée en jeton natif de la chaîne.
NonceCompteur. Nonce de compte : ordonne les transactions d'un émetteur. Nonce source du Bridge : numérote les burns.
CheckpointProchain bloc à lire par le collecteur, persisté avec les événements du lot.
MultisigCompte dont les actions exigent plusieurs signatures (par exemple 2 sur 3).
HSM · coffreMatériel ou logiciel qui protège les clés et signe sans les exposer.
MiCARèglement (UE) 2023/1114 sur les marchés de crypto-actifs, qui encadre notamment les jetons de monnaie électronique.
JHJour-homme : 7 heures de travail effectif.

// contracts/src/Bridge.sol — côté source : burn et notification dans la même transaction
function requestTransfer(uint256 destinationChainId, address recipient, uint256 amount)
    external whenNotPaused nonReentrant returns (bytes32 transferId)
{
    Pair memory pair = _pair(destinationChainId);          // paire configurée et chaîne inchangée
    _validateTransfer(recipient, amount);                  // destinataire non nul, 0 < montant ≤ maxTransfer
    uint256 nonce = nextNonce++;                           // 0, 1, 2… vérifié par le collecteur
    transferId = _transferId(block.chainid, address(this), destinationChainId, pair.remoteBridge,
                             address(token), pair.remoteToken, nonce, amount, recipient);
    token.burnFrom(_msgSender(), amount);                  // dépense l'allowance puis brûle
    emit TransferInitiated(transferId, destinationChainId, _msgSender(), recipient,
                           address(token), pair.remoteToken, pair.remoteBridge, nonce, amount);
}
// côté destination : contrôles, anti-rejeu, quota, puis mint — atomique
function completeTransfer(uint256 sourceChainId, address sourceBridge, address sourceToken,
                          uint256 nonce, uint256 amount, address recipient)
    external onlyRole(EXECUTOR_ROLE) whenNotPaused nonReentrant
{
    Pair memory pair = _pair(sourceChainId);
    if (pair.remoteBridge != sourceBridge || pair.remoteToken != sourceToken) revert PairMismatch();
    _validateTransfer(recipient, amount);
    bytes32 transferId = _transferId(sourceChainId, sourceBridge, block.chainid, address(this),
                                     sourceToken, address(token), nonce, amount, recipient);
    if (processed[transferId]) revert TransferAlreadyProcessed(transferId);
    uint256 epoch = block.timestamp / epochSeconds;
    uint256 total = mintedInEpoch[epoch] + amount;
    if (total > epochMintCap) revert EpochMintCapExceeded(epoch, total);
    processed[transferId] = true;                          // annulé avec le reste si le mint échoue
    mintedInEpoch[epoch] = total;
    token.mint(recipient, amount);
    emit TransferCompleted(transferId, recipient, amount);
}
