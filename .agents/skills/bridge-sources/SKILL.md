# Vérifier les sources techniques

**Entrées.** Affirmation exacte, date, version et périmètre technique ou réglementaire.

## Procédure

1. Rechercher la documentation officielle de la version concernée ou les notes de publication ; ouvrir la source et vérifier qu'elle traite du même mode réseau.
2. Conserver URL directe, date de consultation, passage pertinent reformulé et limites d'applicabilité. Une page latest ne décrit pas automatiquement l'image épinglée.
3. Pour les attentes bancaires, séparer obligation applicable, référentiel volontaire, politique interne et bonne pratique ; laisser l'applicabilité à confirmer lorsqu'elle dépend de l'entité.
4. Relier la source à une décision ou une affirmation. Une documentation fournisseur décrit une capacité, pas la réussite d'une expérience locale.

**Livrable.** Référence primaire vérifiable et distinction entre assertion documentaire et observation exécutée.

**Limite.** Si la source n'est pas accessible ou ne soutient pas le fait précis, garder l'affirmation non vérifiée.
