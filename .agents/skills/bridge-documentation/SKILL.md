# Synchroniser la documentation française

**Entrées.** Code actuel, ADR, registre, preuves et commandes exécutées.

## Procédure

1. Organiser les faits selon exigences reçues, hypothèses, décisions, observations et travaux restants ; citer les affirmations importantes par identifiant.
2. Décrire les commandes réellement utilisables depuis un clone neuf avec prérequis et effets ; mentionner explicitement interruptions et persistance.
3. Utiliser Mermaid pour les flux de confiance et de reprise, sans dessiner un composant futur comme déployé.
4. Construire MkDocs en mode strict, vérifier liens et correspondance entre instructions et essais, puis rapporter toute page historique comme telle.

**Livrable.** Documentation construite, procédures vérifiées et limites à jour.

**Limite.** Ne pas écrire au passé une expérience non exécutée ou une intégration encore désactivée.
