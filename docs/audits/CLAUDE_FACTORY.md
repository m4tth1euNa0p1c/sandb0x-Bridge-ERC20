# Factory Claude — première base

Cette branche conserve le catalogue Codex existant et ajoute un premier rôle Claude en lecture seule et un skill de revue. Les fichiers `CLAUDE.md`, `.claude/agents/bridge-reviewer.md` et `.claude/skills/bridge-review/SKILL.md` sont des configurations projet ; leur découverte et leur comportement par Claude Code restent à tester dans une session réelle.

Le point faible observé dans la revue précédente est l'absence de démonstration du chargement et du comportement des rôles. Cette première adaptation traite le besoin de disposer d'un format Claude distinct ; elle ne prouve pas que la revue est correcte. Cas à rejouer : une modification autorisant le mint sans observation doit produire un constat critique ; une demande sans rapport avec le bridge ne doit pas déclencher automatiquement ce skill. Aucun des deux cas n'a été exécuté avec Claude ici.

Les 50 rôles et skills Codex ne sont pas convertis automatiquement. Leur revue individuelle et les tests comportementaux restent à mener. Les plugins ajoutés ci-dessous fournissent des hooks dont l'exécution n'a pas été validée ; aucune intégration MCP supplémentaire n'a été configurée ici. Les permissions effectives restent celles de l'environnement ; une consigne de lecture seule n'est pas un confinement de sécurité.

Ne pas enregistrer de clé dans Git ni afficher son contenu. Aucune requête API n'a été effectuée. La [documentation Claude Code](https://code.claude.com/docs/en/features-overview) décrit les rôles respectifs des instructions, agents, skills et hooks ; elle ne valide pas cette configuration particulière.
